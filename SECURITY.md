# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of NeaWelcomer seriously. If you discover a security vulnerability (such as packet injection, denial of service vectors, or MiniMessage tag manipulation), please follow responsible disclosure:

1. **Do not open a public GitHub issue.**
2. Send an email to `milansanchz@gmail.com` with:
   - A detailed description of the vulnerability.
   - Proof of concept (PoC) or reproduction steps.
   - Potential impact assessment.
3. You will receive an acknowledgment within 48 hours. Fixes are prioritized and released in security patch versions.
